● VOTAZIONE APERTA
Senza token, alcune azioni apriranno la pagina di modifica su GitHub.
Con token, aggiungere/eliminare racconti e cambiare lo stato avviene in automatico. Crea token →
Come funziona:
Lo stato globale si trova nel file stato.json nella repo, l'elenco dei racconti nel file racconti.json.
Il sito legge entrambi i file a ogni caricamento, così tutti i dispositivi vedono la stessa cosa.
I voti sono conteggiati tramite un servizio esterno condiviso, non nel telefono di chi vota.
Incolla qui il token prima di aggiungere/eliminare racconti o cambiare lo stato: senza token queste operazioni non possono essere salvate per tutti.
Attenzione: non condividere mai questo token con altre persone né inserirlo in documenti/QR code distribuiti: chi lo possiede può modificare l'intero sito.
